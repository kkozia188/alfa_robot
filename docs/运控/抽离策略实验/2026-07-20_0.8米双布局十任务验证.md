# 0.8 米双布局十任务验证

## 当前合同

- 集装箱宽 `1.8m`，箱垛为 3 列 × 5 层，箱体深 `0.30m`、横宽 `0.50m`、高 `0.40m`。
- 居中布局目标：左 `y=+0.45m`、右 `y=-0.45m`。
- 偏差布局按本轮最终约定为：左 `y=+0.50m`、右 `y=-0.40m`；场景和集装箱相对 `base_link` 同步平移 `+0.05m`。
- 外侧箱中心在居中布局为 `y=±0.50m`，附着箱相对末端保留 `0.05m` 横向偏置，不与末端面心共心；偏差布局保持同一偏置口径。
- 侧吸和顶吸统一使用箱墙前表面 `x=0.80m`，不再给顶吸增加车辆前移量。
- `updown` 在 `[0.00,0.70]m` 范围按 `0.01m` 步长完整扫描，共 71 个高度。
- 放置目标 `updown=0.10m`，不再先降至 0.10m 后回升至 0.20m。

## 任务

每套布局运行 `L1/R3、L4/R6、L7/R9、L10/R12、L13/R15` 五组完整循环。居中和右偏布局合计 10 个任务。

## 运行

只运行居中布局：

```bash
ros2 run alfa_robot_moveit_config extract_sequence_rerun.py \
  --task-layout centered \
  --continue-on-failure
```

只运行右偏 0.1m 布局：

```bash
ros2 run alfa_robot_moveit_config extract_sequence_rerun.py \
  --task-layout right_shift_0p1 \
  --continue-on-failure
```

连续运行两套布局：

```bash
ros2 run alfa_robot_moveit_config extract_sequence_rerun.py \
  --task-layout both \
  --continue-on-failure \
  --save /mnt/mydisk/ALFA/alfa_robot/data/ik_benchmark/container_1p8m_15box_flow/ten_tasks_centered_right_shift_x080_full_cycle_corrected.rrd
```

## 结果

严格按上述参数运行，不追加失败补救策略，结果为 `2/10`。居中两组侧吸完整成功。

| 布局 | 任务 | 算法耗时 | 停止阶段 | 原因摘要 |
| --- | --- | ---: | --- | --- |
| 居中 | L1/R3 | 632.4ms | 成功 | 完整循环完成 |
| 居中 | L4/R6 | 744.8ms | 成功 | 完整循环完成 |
| 居中 | L7/R9 | 210.1ms | 抽离 | 32个候选，左臂RRT无可达路径 |

上一版错误地把目标改成 `±0.40m` 后，L1/R3 的338个合法IK全部被 `box_wall_between <-> left_joint6` 拒绝。恢复 `±0.45m` 后，最小复现得到89个去重候选和18个抽离成功候选，确认“全部被附着场景过滤”的假失败已消除。
