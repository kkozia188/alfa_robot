# V3 铲式 5×5 抓取仿真

## 与原单臂吸盘任务的边界

本任务是独立的 `scoop` 末端变体；旧吸盘 5×5 的 V3.0.9 站位仍保留，
但尚未按 V3.1.1 整机重新规划验收：

- 原入口：`v3_5x5_grasp_sequence_rerun.py`；`legacy_suction` 作为兼容别名映射到
  V3.1.1 的 `suction` 末端。
- 铲式入口：`v3_scoop_5x5_grasp_sequence_rerun.py`，显式选择 `scoop`。
- 两套任务使用不同站位 JSON、结果 schema、Rerun application id 和数据目录。
- 整机描述已切换到 `robot_v3.1.1-hybrid`：吸盘配置共26个可动关节，含双轴
  头部、主动悬挂、脚轮/车轮与双7轴手臂；搬箱轨迹仍只记录升降、头部 yaw 和
  双臂16个规划相关关节。`updown=[-1,0]m` 与
  `tool0=[0,0,0.13585]m` 保持不变。

## 场景与任务

- 车头到箱体接触面：`X=0.75m`。
- 箱体：`0.30×0.40×0.40m`，5 列 × 5 排。
- 仓库净尺寸：长 `2.38m`、宽 `2.38m`、高 `2.35m`。
- 地面：`Z=0m`，FCL 碰撞顶面下沉 `5mm`；底盘模型的支撑接触按场景碰撞矩阵处理。
- 25 个箱全部真实抓取，按每排两侧优先、中心最后的顺序处理；已交接箱体
  从后续场景和 Rerun 中移除，不提前清理未抓取箱体。
- 1～15 号除7号顶吸外均正面抓取；16～25号全部顶吸，共14正面、11顶吸。
- 每排从正Y到负Y编号：第1、2列固定左手，第3、4、5列固定右手；中心列
  3/8/13/18/23号均由右手处理，不再进行左右手候选竞争。
- 每箱包含预接触 RRT、5cm 接近、附着、碰撞验证后的抽离、带箱切换高度、
  后方命名姿态放置、释放，以及从释放姿态直接到下一箱预接触位的空载整机过渡；
  中间箱不再回 `home`。常规正面抽离35cm，
  中心3/8/13号缩短至10cm；顶吸抬升20cm。

铲式专用调整位于 `config/v3_scoop_5x5_station.json`：13号正面TCP
在箱面中心下方 `0.10m`；23号顶面吸点沿X偏移 `-0.13m`，距30cm箱面
边缘2cm，以适配新模型底排中心箱的可达窗口。它们不进入旧吸盘配置。

机器人后方仍按未建模传送带处理，但不再维护旧模型下手调的 TCP/箱心槽位。
释放终点直接使用 `named_poses_suction.yaml` 中的权威 `unloading` 关节姿态：
左臂 `[130,-105,-180,20,-90,-30,0]°`，右臂
`[-130,-105,180,20,90,30,0]°`，升降统一为 `-0.30m`。新模型明确规定
`left_is_positive_y`，因此左臂自然落在正 Y 后方、右臂落在负 Y 后方；最终箱心
由实际末端 FK 和抓取附着偏置计算。传送带本体不加入视觉或碰撞场景，箱体释放
后视为被输送走。新 `unloading` 的工具轴仍接近水平，最终结果相对竖直朝下的
最大误差约 `88.46°`；远端命名姿态与上一版“放置末端朝下”不可同时作为
最终关节姿态，本轮以远端 V3.1.1 `unloading` 为准。

## 全程自然运动约束

铲式任务在原有关节距离、腕部奇异点、关节限位和碰撞约束之外，单独启用：

- 每个笛卡尔步围绕上一帧真实冗余角采样 `0°、±1°、±2°`，同时保留全局候选兜底。
- 关节二阶变化权重为 `10.0`，抑制肘腕在相邻冗余解之间来回切换。
- 笛卡尔求解关键点的近端和腕部关节单步均硬限制为 `3°`。
- 已通过碰撞检查的笛卡尔边按最大 `1°` 关节步幅重采样；插值状态继承附着箱，
  不修改关键点、TCP、碰撞许可或抓取距离。
- 最终结果逐箱检查最大帧步幅、相邻帧步幅变化、明显方向反转和累计绕行；
  任一项超过 `motion_acceptance` 合同即不生成成功录制。
- 每条携箱路径用箱体原始上方向计算倾角，硬限制为 `95°`；`>95°` 的明显
  上下翻转状态不进入OMPL结果，并在路径插值复核时再次拒绝。因为权威
  `unloading` 本身约倾斜 `89～91°`，该上限已接近可实现的最严格值。
- 放置阶段只在 `updown=-0.30m` 使用命名 `unloading`：低位抓取先带箱升至
  `-0.30m` 再移臂；高位顶吸先移臂到后方安全区再下降。每2cm做一次整机携箱
  碰撞检查；直接升降不通时先规划到安全携箱姿态。释放后空载恢复任务高度。
- 铲式完整任务固定关闭 `ignore_opposite_arm`；活动臂、携箱和对侧臂之间不设
  碰撞豁免。升降会同时移动双臂，因此升降段使用无规划组过滤的整机FCL检查。
- 顶吸后放使用完整场景碰撞检查后的关节空间 RRT，并对原路径做最小关节行程
  后处理；结果另行检查负载帧数、总关节行程、额外绕行与反向次数。顶吸不再
  执行高失败率的长距离笛卡尔路径重写。
- 正面箱长距离转运优先在笛卡尔空间搜索：TCP 位置做直线插值、姿态做最短四元数球面
  插值，冗余 swivel 角从段起点连续插值到终点，并用解析 IK 求解。后处理会从
  当前点尝试直连最远的后续 RRT 节点；仅当整段关节限位、箱体倾角和完整场景
  碰撞复核全部通过，且关节行程不劣于原路径时才采用。失败段保留关节空间路径
  作为兜底，单次调用最多搜索128个笛卡尔候选段，结果逐箱记录两类执行段数量。
- 首箱从对称 `home` 到预接触位存在解析笛卡尔不可达带，不能用单条 TCP 直线贯通。
  首箱采用混合搜索：OMPL 只生成无碰撞拓扑，捷径图边权使用实际 TCP 平移与姿态
  累计量；最多采样24条过渡、至少比较3条成功轨迹。结果硬限制为 TCP 路径不超过
  `3.6m`、最大直线偏离不超过 `0.9m`、姿态累计不超过 `550°`，不会把混合路径
  误报为整条纯笛卡尔路径。
- 抓取接触时工具 +Z 必须正对接触面法向，铲式吸盘长轴（工具 X）必须水平。
  第7轴滚转采用镜像幅值：左臂 `+90°`、右臂 `-90°`；附着箱的平移、旋转、
  碰撞体和 Rerun 姿态使用同一工具到箱体变换。
- 下一箱IK以上一箱释放关节作为活动臂种子；高度安全时，对侧臂也保留上次姿态。
  箱间优先尝试“先整理手臂、再升降”或相反的两段直连，二者不通才调用整机RRT。
- 箱间过渡最多450帧、双臂累计 `3500°`、额外绕行 `2200°`、30次换向、
  单轴范围 `360°`；超限路径即使无碰撞也会丢弃重采样。
- 非工作臂需要换安全姿态时，过渡拆成两条单臂轨迹顺序执行：先单独收纳
  非工作臂，再冻结它并规划工作臂+升降轴。每条轨迹都要求冻结臂行程不超过
  `0.01°`；成功结果不会使用 `dual_arm` 或 `whole_body` 组让双臂同时搜索。
- RRT 成功后，最多保留64个代表节点，对经过完整场景碰撞复核的可直连边求
  最小加权关节行程路径，再按最大 `3°` 单步重采样；任何捷径失败都保留原始
  已验证路径。
- 固定手臂与升降高度来自 `VERIFIED_SELECTION`，不允许失败后静默换高度。
  每箱尽量比较2条成功轨迹，至少1条满足完整质量合同即可；20号保留3条，
  难箱仍有界扩展到12条（2/3/4号上限24条）。
  选优同时考虑总关节行程、段内多余行程、明显反向次数和单电机活动范围。
- 后方放置完整单箱硬门槛为：七轴累计总行程不超过 `3000°`、段内多余行程不超过
  `1000°`、明显反向不超过20次、任一电机累计活动范围不超过 `360°`、单帧不超过
  `3°`；升降累计不超过1m、单步不超过2cm，释放帧与权威 `unloading` 七关节
  姿态的最大误差不超过 `0.01°`。
  顶吸完整周期另限制总行程 `3000°`、反向25次；带箱后放最多220帧、
  总行程不超过 `1650°`、多余行程不超过 `850°`、反向不超过20次。

这些门槛只针对 V3.1.1 的新任务；旧模型的轨迹指标见后文历史结果。

## Shortcut 局部关节 RRT（2026-09-19）

`v8` 规划合同不把降维定义为缩小 TCP 空间，而是修补已知 shortcut：

- 先对当前状态到目标逆解做7轴最短角插值，得到主体路径并定位连续碰撞窗。
- 在碰撞窗中逐关节探测；单关节能产生合法状态时只选1轴，否则枚举关节对，
  最多选择2轴。RRT 状态为路径进度和这1～2轴相对 shortcut 的偏移，其余轴
  始终沿主体路径插值。
- 碰撞窗前后各保留最多6个 shortcut 采样点，让偏移平滑进入和退出；找到通路后
  再在同一1D/2D子空间做最远可直连 shortcut，去除树回溯锯齿。
- 每个状态和插值边都复核关节限位、完整 PlanningScene/FCL、携箱95°倾角，
  以及相对原 shortcut 的 TCP 位置 `0.18m`、姿态 `35°` 走廊；起点和目标逆解
  必须精确保持。局部修补失败才进入完整7轴 RRT。
- 单次局部搜索预算 `1800ms/800样本`；summary 逐段记录策略、修补关节、窗口、
  样本、局部/完整RRT耗时和诊断原因。

完整序列结果位于
`data/ik_benchmark/v3_scoop_5x5/2026-09-19-joint-shortcut-rrt/`：

- 抓取/过渡 `25/25`；选中轨迹核心规划平均 `2.60s`、中位 `1.31s`，22/25箱
  不超过5s；含ROS进程启动平均 `3.51s`、中位 `2.21s`，21/25箱不超过5s。
- 9号带箱段仅发散右J4，局部搜索 `171.76ms`；平滑后完整箱换向6次，选中进程
  `1.39s`。8号空载过渡仅发散右J1，局部搜索 `7.68ms`。
- 不适合1～2轴修补的路径明确记录为 `joint_rrt_fallback`；所有候选、失败和
  箱间过渡累计搜索墙钟 `477.54s`，不与单条选中轨迹耗时混淆。
- 大步关节翻转事件0、携箱倒置帧0、最大倾角 `94.84°`；总行程
  `46164.65°`，默认回放时间轴 `139.85s`。
- Rerun 记录 TCP 分段路径和逐箱搜索时间曲线；HTML/CSV 同步提供逐箱搜索、
  路径、关节行程、换向/翻转和总时间数据。

## 首箱直接抓取分支（2026-09-21）

首箱旧预接触逆解的左J1约为 `-151°`，与 `home` 的 `+155°` 在角度圆上看似只差
约54°，但J1是 `[-180°,180°]` 有限位关节，不能跨边界执行，实际路径只能绕约
306°。`v9` 对首箱候选增加有限位关节跨边界惩罚，并在首段验收中加入“实际
累计行程减端点最短角”的单轴绕圈余量，最大允许100°。

新首箱选择正角度解析分支，左J1为 `+155° -> +167.1°`。直接关节插值仍会
碰撞，因此使用完整场景验证的RRT短路径，但不再整圈旋转：首段帧数
`135 -> 78`、关节行程 `901.22° -> 755.45°`；首箱完整动作换向 `13 -> 4`，
核心规划约 `1.20s`。完整序列保持抓取/过渡 `25/25`，后续箱起点不变，结果位于
`data/ik_benchmark/v3_scoop_5x5/2026-09-21-first-grasp-direct/`。

### 4号与6号低位放箱优化（v10）

### 7号正吸与20号路径热启动（v11）

7号由顶吸改为左臂正吸。逐5cm升降扫描确认：`updown=0.00m`可以完成正面

20号保留顶吸。其抓取/抽回末态在重复规划中完全一致，因此从已批准的带箱路径

`739.28°/82.07°额外行程/3次换向`。

除7号和20号外，其余23箱任务对象逐项不变；两箱释放末态与上一版误差0。
完整序列抓取/过渡 `25/25`，选中任务核心规划全部不超过5秒，平均 `1.69s`、
最大 `4.90s`；总行程 `41476.71°`。结果位于
`data/ik_benchmark/v3_scoop_5x5/2026-09-21-box7-front-box20-fast/`。

## 仿真边界

当前验证的是运动学、刚体附着、MoveIt/FCL 碰撞和 OMPL 路径，不模拟真空、
接触压力、密封、箱体变形或铲板受力。后方传送带未建模，箱体到达命名卸货
关节姿态并释放后“消失”表示被传送带输送走，不是物理动力学仿真。23号吸点
距箱面边缘仅2cm，实机前需验证吸盘有效接触面积与箱体稳定性。
