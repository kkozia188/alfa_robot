# 2026-10-03 附着碰撞球坐标修复

`loaded_robot()` 此前硬编码旧 link7→tool0 旋转，箱体外观则读取当前 URDF，造成附着40球与真实箱体错位。现从传入机器人配置的 URDF 读取 tool0 固定关节 origin，与外观统一使用 canonical_side_tool_to_box。

验证：当前抽离候选，在固定底盘和 mobile_base_18d_current 两模型中，左右各40球共160球的 GPU FK 球心与 yourdfpy 箱体世界变换的最大误差小于0.00036mm。该候选重新通过碰撞、地面和稳定性检查。

此前基于错误附着球变换的349候选统计、旧24球4个/新40球44个碰撞通过统计不再作为有效验收证据。当前只重验了所展示的单个候选，并未宣称整条规划成功。
