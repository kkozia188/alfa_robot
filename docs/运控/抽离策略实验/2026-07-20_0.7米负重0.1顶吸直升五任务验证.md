# 0.7 米箱墙、负重 0.1 米与顶吸直升五任务验证

## 本版规则

- 箱墙前表面由 x=0.80m 调整为 x=0.70m。
- L1/R3、L4/R6、L7/R9 使用双侧吸和箱体位姿 RRT 抽离。
- L10/R12、L13/R15 使用双顶吸；吸附后保持 12 个机械臂关节不动，updown 固定上升 0.40m，不调用抽离 RRT。
- 吸附后负重目标姿态的 updown=0.10m。
- 放置循环保持启用，放置姿态的 updown=0.10m。
- 全过程继续使用机器人、附着箱、箱墙和集装箱碰撞检查。

## 运行命令

~~~bash
source /opt/ros/humble/setup.bash
source /mnt/mydisk/ALFA/alfa_robot/ros2_ws/install/setup.bash
cd /mnt/mydisk/ALFA/alfa_robot/ros2_ws

ros2 run alfa_robot_moveit_config extract_sequence_rerun.py \
  --task-layout centered \
  --continue-on-failure \
  --save /mnt/mydisk/ALFA/alfa_robot/data/ik_benchmark/container_1p8m_15box_flow/five_tasks_x070_loaded010_top_direct_lift040.rrd
~~~

## 结果

| 任务 | 模式 | 结果 | 总计算时间 | 结论 |
| --- | --- | --- | ---: | --- |
| L1/R3 | 双侧吸 | 失败 | 1916.3ms | 抽离成功候选进入负重阶段，但 8 次负重候选中无成功方案 |
| L4/R6 | 双侧吸 | 失败 | 1920.3ms | 抽离成功候选进入负重阶段，但 8 次负重候选中无成功方案 |
| L7/R9 | 双侧吸 | 失败 | 3755.6ms | 负重过渡时左侧携带箱与中间箱墙冲突，局部 RRT 未修补成功 |
| L10/R12 | 双顶吸直升 | 成功 | 482.1ms | updown 0.14→0.54m，精确上升 0.40m，完成全循环 |
| L13/R15 | 双顶吸直升 | 成功 | 1094.6ms | updown 0.03→0.43m，精确上升 0.40m，完成全循环 |

成功率为 2/5。本轮不调整搜索速度，也不放宽碰撞条件。
