# V3 七轴冗余解析 IK

`V3RedundantArmAnalyticIk` 面向 V3 七轴机械臂。当前运行模型是 V3.1.1；V3.0.4～V3.0.9 几何仅保留给历史回归，不得作为当前 Demo 的求解器。

## 求解形式

给定末端目标位姿 `T`、冗余角 `psi` 和离散分支 `b`，求解器直接计算：

```text
q = F(T, psi, b)
```

这里不是把七个关节近似写成全局线性的 `q0 + lambda * n`。机械臂运动学是非线性的；只有在当前姿态附近，才可写成局部形式：

```text
q(psi + dpsi) ~= q(psi) + n(q) * dpsi
J(q) * n(q) = 0
```

受支持模型的 Joint1/2/3 共点、Joint3/4/5 共点、Joint5/6/7 共点，因此可以使用球肩—肘—球腕闭式分解：

1. 从目标位姿减去腕心到工具的固定偏移，得到腕心 `W`。
2. 肩心 `S`、腕心 `W` 和两段臂长确定一个肘部圆。
3. `psi` 在这个圆上唯一选择肘部位置 `E`。
4. 由 `S→E` 闭式分解 Joint1/2。
5. 由 `E→W` 闭式分解 Joint3/4。
6. 由剩余末端朝向闭式分解 Joint5/6/7。
7. 输出肩、肘、腕离散分支，进行关节限位、FK 回代和去重。

各版本几何量由对应 URDF 固定变换分别计算。当前 V3.1.1 以 `arm_carriage` 为解析坐标系，关键几何量由 V3.1.1 固定关节变换计算：

- 左肩心：约 `(0.181, 0.468061833, 1.374938842) m`
- 右肩心：约 `(0.181, -0.476590193, 1.374938842) m`
- 上臂：`0.506 m`
- 前臂：`0.473 m`
- 腕心到 `tool0`：工具坐标系 `+Z` 方向 `0.13585 m`

## `psi` 的物理意义

`psi` 是肘部绕“肩心—腕心连线”的旋转角，也叫 swivel angle / arm angle。改变它时，目标末端位置和朝向保持不变，但肘部和整条手臂的构型发生变化。

它可以作为一维优化变量，用于：

- 增大机器人自碰撞和环境碰撞余量；
- 远离 Joint2、Joint4、Joint6 等关节限位；
- 选择更舒适、连续、接近当前姿态的构型；
- 降低相邻轨迹点的关节跳变；
- 避开奇异位形；
- 结合动力学模型降低力矩或能耗。

因此上层不需要盲目生成 32～64 个七维随机 seed。更合适的方式是在一维 `psi` 上做少量确定性采样或区间优化，再对每个 `psi` 的有限个解析分支做碰撞和代价筛选。

## 当前边界

- 每个 `V3RedundantArmModel` 严格绑定对应版本、侧别的关节固定变换和限位，调用方不得混用模型枚举。
- 求解器只负责运动学、限位、分支、去重和 FK 精度验证，不负责碰撞检测。
- 当前 V3.1.1 以及历史 V3.0.7～V3.0.9 的目标位姿使用 `arm_carriage` 坐标；其他历史版本按各自模型定义转换。
- 在肘部完全伸直等退化位形，`psi` 本身失去几何意义，求解器使用 seed 固定耦合自由度。
