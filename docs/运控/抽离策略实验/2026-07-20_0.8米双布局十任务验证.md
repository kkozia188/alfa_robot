# 0.8 米双布局十任务验证

## 当前合同

- 集装箱宽 `1.8m`，箱垛为 3 列 × 5 层，箱体深 `0.30m`、横宽 `0.50m`、高 `0.40m`。
- 居中布局目标：左 `y=+0.40m`、右 `y=-0.40m`。
- 右偏 0.1m 布局按本轮约定转换为：左 `y=+0.50m`、右 `y=-0.30m`；场景和集装箱相对 `base_link` 同步平移 `+0.10m`。
- 外侧箱中心为 `y=±0.50m`，因此附着箱相对末端保留 `0.10m` 横向偏置，不与末端面心共心。
- 侧吸和顶吸统一使用箱墙前表面 `x=0.80m`，不再给顶吸增加车辆前移量。
- `updown` 在 `[0.00,0.70]m` 范围按 `0.01m` 步长完整扫描，共 71 个高度。
- 放置目标 `updown=0.10m`，不再先降至 0.10m 后回升至 0.20m。

## 任务

每套布局运行 `L1/R3、L4/R6、L7/R9、L10/R12、L13/R15` 五组完整循环。居中和右偏布局合计 10 个任务。

## 运行

只运行居中布局：

```bash
ros2 run alfa_robot_moveit_config extract_sequence_rerun.py \
  --task-layout centered \
  --continue-on-failure
```

只运行右偏 0.1m 布局：

```bash
ros2 run alfa_robot_moveit_config extract_sequence_rerun.py \
  --task-layout right_shift_0p1 \
  --continue-on-failure
```

连续运行两套布局：

```bash
ros2 run alfa_robot_moveit_config extract_sequence_rerun.py \
  --task-layout both \
  --continue-on-failure \
  --save /mnt/mydisk/ALFA/alfa_robot/data/ik_benchmark/container_1p8m_15box_flow/ten_tasks_centered_right_shift_x080_full_cycle.rrd
```
