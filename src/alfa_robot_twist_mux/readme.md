# alfa_robot_twist_mux

## 项目简介

`alfa_robot_twist_mux` 是基于 `twist_mux` 的速度控制仲裁功能包，用于管理机器人多路运动控制来源，包括自主导航、手动遥控、急停等。

并且有一个键盘控制输出指令的节点。

------

## 输入话题（控制源）

| 控制来源 | 话题名称          | 优先级 | 说明                |
| -------- | ----------------- | ------ | ------------------- |
| 自主导航 | `/cmd_vel_nav`    | 10     | 导航自动控制        |
| 手动遥控 | `/cmd_vel_teleop` | 100    | 键盘 / 手柄手动控制 |
| 急停控制 | `/cmd_vel_estop`  | 255    | 系统级安全急停      |

------

## 输出话题

| 话题名称   | 说明                     |
| ---------- | ------------------------ |
| `/cmd_vel` | 最终输出至底盘的速度指令 |

------

## 核心模块说明

### twist_mux（速度仲裁器）

负责多路速度输入的选择与切换。

- 根据优先级自动选择当前有效控制源
- 输入信号超时自动失效
- 支持锁存机制，禁止异常速度输出

### 键盘遥控节点

用于手动控制机器人运动。

- 支持 WASD 按键控制
- 以 10Hz 频率持续发布速度
- 松开按键自动停止
- 输出话题：`/cmd_vel_teleop`

------

## 启动方式

### 单独启动键盘遥控

```bash
ros2 run alfa_robot_twist_mux teleop_ctl_node
```

### 启动多路控制系统

```bash
ros2 launch alfa_robot_twist_mux bringup.launch.py
```

启动内容：

- twist_mux 速度仲裁器
- 急停安全节点

------

## 使用注意事项

- 遥控节点为长按输入，需要持续信号才能保持输出。
- 急停通过 `/estop` 话题触发，收到 True 后立即输出零速度并屏蔽其他控制。
- 所有速度指令必须经过 twist_mux 仲裁，禁止直接发布到 `/cmd_vel`。
