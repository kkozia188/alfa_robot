# 三平行六轴机械臂闭式解析解

## 结论

`alfa_robot_analytic_ik::ThreeParallelArmAnalyticIk` 已不再对 `joint1` 做网格扫描或二分求根。当前六轴逆解由有限个闭式分支组成：

1. `joint1`：一阶三角方程直接给出至多 2 个分支；
2. 腕部姿态：`joint5` 的正负余弦分支各 1 组，腕部奇异点给出靠近 seed 的代表解；
3. 平面肘部：余弦定理给出至多 2 个分支；
4. 最多组合为 8 组候选，最后按关节限位、正解误差、重复解过滤。

## joint1 闭式方程

目标工具位姿在单臂基座坐标系中记为位置 `p=(px,py,pz)`，工具 z 轴为目标旋转矩阵第三列 `n=(nx,ny,nz)`。定义：

```text
L = joint6_x + tool0_z = 0.0825 + 0.259
s = 左臂 +1，右臂 -1
D = parallel_plane_offset + joint5_z = 0.1265 + 0.058
```

由 `joint2/3/4` 三平行轴的运动平面约束消元得到：

```text
(-px + L·nx) sin(q1) + (py - L·ny) cos(q1) = s·D
```

令：

```text
A = -px + L·nx
B =  py - L·ny
R = hypot(A, B)
φ = atan2(B, A)
```

则：

```text
sin(q1 + φ) = s·D / R
q1_1 = asin(s·D/R) - φ
q1_2 = π - asin(s·D/R) - φ
```

若 `|s·D| > R`，目标不存在满足三平行平面约束的实数 `joint1`。

## 其余关节

- 固定 `joint1` 后，通过目标旋转矩阵分解得到腕部两组 `joint5` 分支，并计算耦合角 `a=q2+q3+q4` 和 `joint6`；
- 扣除腕部和工具偏移后得到 `joint4` 轴位置；
- `joint2/3` 使用平面二连杆余弦定理求肘上/肘下两组解；
- `joint4 = a - joint2 - joint3`。

## 奇异点

当 `cos(joint5)=0` 时，`a` 和 `joint6` 耦合、逆解不唯一。实现保留 seed 中的 `joint6`，再由旋转矩阵闭式恢复对应的 `a`，得到连续且确定的一组代表解。

## 验证

Debug 测试覆盖：左右臂各 5000 个随机关节状态、所有返回分支的正解复核，以及左右臂 `joint5=±90°` 腕部奇异姿态。位置和姿态误差阈值均为 `1e-5`。
